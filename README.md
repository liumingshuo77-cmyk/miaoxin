# 秒薪

上班之后看这一秒值多少钱。工资摊到秒，今天的股价盈亏和房租也算进去。

![秒薪主界面](preview.png)

正面只有数字。右上角「设置」翻到背面填月薪、班次、打卡、房租、开销、股票和休假，填完点「完成」翻回来。

## 打开

Windows 上双击 [`秒薪.exe`](秒薪.exe)，不用安装 Python。系统需要自带的 Edge WebView2，Windows 11 一般已经有了。

也可以双击 `启动秒薪.bat`。没有 exe 时，它会用本机的 Python 启动；缺 pywebview 时顺手装上。

从源码运行：

```bat
py -3 -m pip install -r requirements.txt
py -3w 秒薪.pyw
```

改完界面或计算后，重新打包：

```bat
py -3 build_exe.py
```

### macOS

Mac 版使用系统 WebKit，沿用同一套界面、工资计算和股票记账功能，支持原生标题栏、最小化、关闭和 `Command-Q` 退出。

已有构建产物时，双击 `dist/秒薪.app`，也可以把它拖进「应用程序」。`.app` 自带 Python 和依赖，运行时不用安装 Python。

从源码运行需要 Python 3.10 或更新版本。在项目目录执行：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python 秒薪.pyw
```

也可以双击 `启动秒薪.command`：优先打开本目录已构建的 `.app`；否则创建项目内的 `.venv` 并安装运行依赖后启动。首次安装需要联网。

在 Mac 上构建独立应用：

```sh
.venv/bin/python -m pip install -r requirements-build.txt
.venv/bin/python build_mac.py
open dist/秒薪.app
```

构建产物采用当前 Python 的架构。Apple Silicon 和 Intel 分别在对应架构的 Python 环境构建；这不是通用二进制。可运行的最低系统版本取决于构建时的 Python 和依赖，建议在目标系统验证。构建脚本使用本机临时签名，未配置 Apple Developer ID 签名或公证；从网上下载的应用可能被 Gatekeeper 拦截。确认来源后，可按系统提示在「系统设置 → 隐私与安全性」中允许打开，或自行从源码构建。

开发验证：

```sh
node test_calc.js
.venv/bin/python -m unittest discover -s tests
# Mac 桌面会话中运行：实际打开两次 WebKit 窗口，验证保存、重启和退出
.venv/bin/python tests/smoke_macos.py
```

## 正面

| 看到的 | 含义 |
| --- | --- |
| 时钟 | 当前时间，秒在走 |
| 今日 | 今日工资 + 今日股票 − 当天房租 |
| 🍖 吃肉 / 🍜 吃面 | 今日股票赚了吃肉，亏了吃面 |
| 09:30–19:00 | 今天记下的上下班。下班空着就是还在上班 |
| 昨日 | 记在昨天的开销 |
| 房租 | 月租摊到今天的那一份 |
| 元/时 · 元/秒 | 由月薪和标准工时算出来 |
| 工资、股票 | 今天这两块各是多少 |
| 进度条 | 班次里已经计入工资的时间 |
| 多上 / 白上 | 今天股价的盈亏，大约相当于上了多少分钟班 |
| 本月 | 所赚、工资、股票、开销 |
| 月底 | 剩下的工作日如果全勤，再扣掉整月房租，大约还剩多少 |

本月开销是已经记下的花费，加上截至今天摊掉的房租。还没发生的开销不放进月底预估。

## 背面

**今日。** 填今天实际的上班、下班时间。不会一到点就打卡，所以这里是补记。点「按班次」会填上设定的上班时间，并清掉下班时间。早于班次开始的那段不计薪。

**昨日。** 昨天花掉的钱写在这里，记在昨天的日期上。昨天如果属于上个月，就不进本月。房租有单独的一栏，不要再写进昨日开销。

**薪资。** 月薪按你自己的口径，税前或到手都行。房租填一个月的金额，按当月自然日平均，每天扣一份，休息日也扣。11 月月租 3000，就是每天 100；4 号这天，今日扣 100，本月已经扣 400，月底扣满 3000。

上下班和午休只在这里改。加班倍率从 0 到 3，一档 0.1。0 倍时，下班之后和休息日的打卡不计薪。1 倍按平时的秒薪，3 倍是三倍。

工作日默认周一到周五。勾上「2026 放假」后，使用国务院办公厅国办发明电〔2025〕7号里的放假和调休。2027 年还没有公布放假，先按勾选的工作日，要休息或加班就到日历上点。「午休不计」勾上后，午休那一段不发工资。

**股票。** 用代码或名称搜索，填股数，成本可以后补。支持 A 股 6 位代码、港股、美股字母代码。行情大约每 5 秒从腾讯证券取一次，换成人民币。港股、美股如果腾讯的日线接不上月初，月初价改向雅虎财经取。报价有延迟，只给自己记账。

持仓旁边有两个动作。**已卖出**填卖出价后结算，盈利按卖出价减去成本，记在卖出当天，加进今日和本月。**移除**只是删掉，不记账。卖错了可以在「已卖出」里撤销。没填成本不能结算。

**休假。** 点一天，在默认、带薪、无薪、休息、加班之间切换。和当天默认状态一样时，这条修改会取消。

## 工资怎么摊

月薪除以本月计薪日，得到一天的工资。计薪日是勾选的工作日，加上调休上班，去掉放假。

一天的标准工时是班次长度减去午休。秒薪是日薪除以这些秒。时薪是秒薪乘以 3600。

打卡时间和班次重叠的部分，按秒薪累加。午休扣掉。班次结束之后，以及休息日整段打卡，乘加班倍率。带薪休假不看出勤，按一整天计入。无薪休假这一天是 0。

过去没填下班时间的打卡，会在那一天的班次结束时自动补上下班。如果是班次结束后才开始的，则按开始后再加 3 小时收口。

## 股票怎么进账

今日股票是现价相对昨天收盘的盈亏。本月股票是现价相对月初之前最后一个收盘价的盈亏。两笔都换成人民币，分别加进今日和本月。

还没卖出时，相对买入价的盈亏只在持仓旁边显示。卖出结算之后，这笔盈利才进入今日和本月。

## 账本

设置、打卡、开销、持仓和休假都写在本机的 `state.json`，这个文件不会上传。

- **Windows：** 仍在程序旁边。换电脑时把它和 `秒薪.exe` 放在一起。
- **macOS：** 源码运行和 `.app` 共用 `~/Library/Application Support/Miaoxin/state.json`；退出应用后复制此文件即可备份。日志也在同一目录，更新或移动 `.app` 不会移动账本。在 Finder 中按 `Command-Shift-G`，粘贴 `~/Library/Application Support/Miaoxin` 即可打开目录。

从 Windows 迁移时，先退出两边的秒薪，备份 Mac 现有账本，再把 Windows 的 `state.json` 复制到上述 Mac 目录。应用不会自动覆盖或合并旧账本。

测试或使用独立账本时，可设置环境变量 `MIAOXIN_DATA_DIR` 指向另一目录；不会读取或迁移默认目录中的账本。
